This repository houses the first level in my liminal escape room game. 

You can play it here: https://onyx310.github.io/Escape-Room-Level1-Playable/

In this level the player explores an abandoned library in which there is one book that contains a password to the computer. On this computer, in the files, there is a randomly generated passcode that unlocks the door in this level and allows you to leave. 

I wrote all scripts in C# and made all of the game assets in Blender. I also made the song on the title page.
